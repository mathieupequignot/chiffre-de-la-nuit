Politique de confidentialité

Dernière mise à jour : 1er novembre 2026.

« Le chiffre de la nuit » est utilisé uniquement par son auteur, sur son propre compte TikTok.

Données utilisées : le jeton d'accès TikTok de l'auteur, nécessaire pour déposer une vidéo dans ses brouillons (autorisations user.info.basic et video.upload). Ce jeton est stocké de façon chiffrée dans les secrets GitHub de l'auteur et n'est jamais partagé.

Aucune donnée d'autres utilisateurs n'est collectée, stockée, vendue ou partagée. Aucun cookie ni outil de mesure d'audience n'est utilisé.

L'autorisation peut être retirée à tout moment depuis les paramètres de l'application TikTok. Contact : via le dépôt github.com/mathieupequignot/chiffre-de-la-nuit.
